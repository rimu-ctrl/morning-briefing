DB 설치와 데이터 준비 없이 SQL을 연습할 수 없을까?

#DB#설치와#데이터#준비

대학교에서 SQL을 처음 배울 때, 저는 SELECT 문보다 설치 화면을 먼저 오래 봤습니다. 문법을 외워도 연습할 데이터가 없으면 JOIN도 GROUP BY도 연습할 수 없었죠. 그래서 DB 설치와 데이터 준비 없이 브라우저에서 바로 SQL을 실행할 수 있는 서비스 'NULL지마'를 만들었습니다. sql.js로 SQLite를 브라우저에서 돌리고, 6개 테이블로 관계를 채운 뒤 문자열이 아니라 실행 결과와 변형 데이터로 재검증하는 채점 로직을 붙인 과정을 정리했습니다.

✓ 자동 저장됨 · 다른 기기에서도 동일하게 보여요

🇰🇷 핵심 요약

  • SQL 학습자들이 설치 과정에 소요되는 시간을 줄이고, 실습에 집중할 수 있도록 하는 서비스 'NULL지마'가 개발되었습니다.
  • 이 서비스는 브라우저에서 직접 SQL을 실행할 수 있게 하여, 데이터베이스 환경 설정 없이도 학습할 수 있는 편리함을 제공합니다.
  • sql.js를 활용해 SQLite를 구현하고, 다양한 테이블과 관계를 통해 실질적인 데이터를 사용할 수 있어, 학습 효과를 극대화합니다.
  • 이를 통해 SQL 문법을 쉽고 빠르게 익히는 동시에, 코드 실행 결과를 바로 확인하며 실습의 이해도를 높일 수 있습니다.
  • 이러한 변화는 SQL 교육의 접근성을 높이고, 데이터베이스 관련 기술 습득을 촉진하는 긍정적인 영향을 미칠 것으로 기대됩니다.
