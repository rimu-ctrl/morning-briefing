생성형 UI 기술을 적용하면 AI가 같은 정보도 받는 사람에 맞춰 화면과 메시지를 다시 짭니다. 넷플릭스 썸네일, 토스 홈, 듀오링고 알림처럼 이미 곁에 온 생성형 UI(GenUI)의 상용 사례가 많습니다. 이러한 사례와 효과, 이를 가능케 한 JSON·컴포넌트 매핑 원리, 다크 패턴·접근성·인종 편향 같은 그림자를 정리했습니다. AI가 정교해질수록 오히려 사람이 다듬지 않은 날것의 메시지가 희소해지는 역설도 함께 살펴봅니다.

  • 생성형 UI(GenUI) 기술은 개인 맞춤형 정보를 제공하여 사용자의 경험을 최적화합니다.
