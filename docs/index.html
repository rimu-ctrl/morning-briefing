  • 새로운 푸시 구조는 외부 이벤트를 실시간으로 클로드 세션에 적용할 수 있도록 하여, 더 즉각적이고 유연한 반응을 가능하게 합니다.

#개인용#AI#에이전트#‘openhuman’
